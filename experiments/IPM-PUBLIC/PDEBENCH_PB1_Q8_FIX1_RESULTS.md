## Scientific interpretation

Q8-FIX1 rules out a simple "learn the PDE better", "increase N", or "swap the local jet" repair.

A crucial regime distinction is now visible.

At low viscosity, Burgers approaches a shock-forming conservation law. The PDEBench trajectories are generated by a finite-volume limited-flux solver and represent discrete cell averages. Pointwise classical derivatives become singular/ill-conditioned near shocks, so a strong-form jet residual need not improve monotonically as grid spacing decreases.

The current IPM transport runtime executes `T(u)u_x` through a semi-Lagrangian characteristic shift. For smooth solutions this is equivalent to conservation form. Near shocks it does not enforce the conservative entropy weak solution.

For a P13 transport term,

`u_t = T(u) u_x + ...`

there is an exact deterministic compiler transformation:

`u_t + dF(u)/dx = ...`

with

`F'(u) = -T(u)`.

For polynomial `T(u)`, `F(u)` is available analytically and introduces no new learned parameters.

The next experiment therefore targets the native runtime only: compare the frozen legacy semi-Lagrangian executor with parameter-free conservative finite-volume execution of the same identified differential law.
