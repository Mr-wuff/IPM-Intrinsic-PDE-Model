## Main failure: intrinsic second-order Taylor flow

For Heat, Advection, Burgers, and Allen-Cahn at base resolution, Cartan-T2 nearly matches external Heun using the same learned Q.

For KdV, Cartan-T2 becomes catastrophically unstable:
- mean base Cartan-T2 final field error: ~8.48e9
- Euler: ~0.0672
- Heun: ~0.0595

Large-dt Cartan-T2 errors reach 1e8-scale and above.

This failure is consistent with the high-order/stiff/dispersive temporal curvature induced by the learned PDE characteristic. Explicit truncation of the intrinsic time Lie/Taylor series is not a universally stable flow integrator.

## Important theoretical correction

The IPM-native object should be the **continuous evolutionary vector field** generated by the learned characteristic Q, not a specific truncated explicit Taylor time integrator.

The exact model evolution is conceptually:

[
u(t+Delta t)=exp(Delta t V_Q)u(t).
]

A numerical integrator approximates this flow and should remain a replaceable solver interface.

Therefore:
- Q_theta + Cartan prolongation + evolutionary vector field remain candidate IPM core;
- Cartan-T2 is demoted from architecture definition to an experimental explicit flow approximation.

## Audit-design issue

The M2 temporal-curvature audit compared V_Q(Q) with the finite difference of Q_theta along the **reference PDE trajectory**.

If Q_theta is imperfect, this mixes PDE fitting error with the mathematical consistency of the learned vector field.

The corrected structural audit must compare V_Q(Q) with a small-h finite difference along the **learned Q flow**.

## Reference-solver issue

At KdV N=512, Euler/Heun/Cartan evaluation rows all become NaN. The M2 reference RK4 used a fixed substep rule and omitted the spectral stiffness guard used in earlier experiments. Future experiments must restore a resolution/order-aware reference timestep, especially for dispersive k^3 dynamics.
