# IPM-M2 — First-Principles Cartan Evolution Core

## Why M2 exists

M1-FIX2 passed its preregistered mechanism gates and established that:
- local jet coordinates are useful;
- derivative-order structure matters;
- pointwise local laws transfer across discretizations better than index-space convolutions.

However, the current PointwiseOrderIPM is still only a mechanism prototype. Its learnable core is a conventional pointwise neural network with architectural and loss additions around it.

M2 returns to the original IPM thesis and asks what the model should be if it is derived directly from the mathematics of local PDE evolution.

## Finite-order closure

If (Q_	heta) depends on (J^k u), evaluating (D_x^pQ_	heta) requires support coordinates up to (J^{k+p}u).

M2 therefore separates:

- **physical law order (k)** — coordinates visible to (Q_	heta);
- **support order (K)** — additional holonomic coordinates used only by Cartan differentiation.

The support jet is always reconstructed from the master field and is never recurrent memory.

This resolves the finite-jet closure issue explicitly.

## M2 scientific questions

1. Can the Cartan total derivative of a learned local law match the spatial derivative of that law without grid-dependent differentiation of the network output?
2. Can the induced evolutionary vector field generate correct temporal curvature (u_{tt})?
3. Does an intrinsic second-order time jet improve time-step transfer relative to Euler, and remain competitive with external Heun integration using the same learned (Q_	heta)?
4. Does the learned law Jacobian recover the correct differential-order dependence of controlled PDEs?
5. Does this architecture retain grid invariance while using no convolution, attention, FNO layer, or PDE-residual loss?

## Controlled PDEs

Each family is trained separately in M2. No PDE-family token is used.

## Baselines

All rollout methods use exactly the same trained characteristic network (Q_	heta):

- Euler: external first-order integration;
- Heun: external second-order integration;
- Cartan-T2: IPM-native second-order time jet.

This isolates the intrinsic evolution law from backbone capacity.

## Training

The characteristic is trained only on instantaneous generator targets (u_t).

No:
- convolution;
- attention;
- Fourier neural operator;
- symbolic PDE library;
- PINN residual;
- Sobolev loss;
- spectrum loss;
- rollout fine-tuning.

The purpose is to test the mathematical IPM core with as little auxiliary machinery as possible.
