## Scope
First formal mechanism qualification for Intrinsic PDE Model (IPM).

## Core architecture
IPM learns only the base infinitesimal generator:
[
Q_\theta(J^k u,\lambda)=u_t.
]

Higher differential-state evolution is generated by intrinsic prolongation:
[
\partial_t u_\alpha = D_\alpha Q_\theta.
]

The formal M0 jet order is (k=3).
