# Public Benchmark Transition Plan

## Why the benchmark strategy changes

Internal B0/B1 experiments were useful for:
- architecture qualification;
- controlled equal-update training;
- latency/profiling;
- detecting implementation defects;
- freezing IPM-v1.

They are not sufficient as the primary paper comparison because the competing models were retrained inside our own harness.

From this point, primary benchmark evidence should come from established public benchmark protocols and official pretrained/published baselines wherever possible.

## Priority 1 — PDEBench official protocol

PDEBench is the immediate primary benchmark because current frozen IPM-v1 is already compatible with the benchmark's 1-D local evolution tasks.

Official repository commit pinned for the first public run:
`4ff3e3a4aa1561721b5571fa3a048a0a463e0568`

Official 1-D Advection/Burgers config:
- reduced_resolution = 4
- reduced_resolution_t = 5
- initial_step = 10
- t_train = 200
- batch_size = 50
- epochs = 500 for official neural baselines
- FNO modes = 12, width = 20

PDEBench's own forward script explicitly includes:
- 1D Advection beta=1.0
- 1D Burgers nu=0.01
for FNO / U-Net / PINN.

Official pretrained baseline artifacts are publicly released on DaRUS.

### IPM public-track policy

Two IPM entries should be kept distinct:

1. **IPM-v1 frozen / low-data**
   - current Q3-FIX2/Q4 frozen programs;
   - trained/discovered from only the historical IPM training subset;
   - no benchmark-specific refit;
   - evaluated under the official PDEBench spatial/temporal reduction and official metric function.

2. **IPM-PDEBench standard-data**
   - architecture remains frozen;
   - may be fitted using only the official PDEBench training split and official data contract;
   - no baseline-specific architectural change;
   - used only if a standard-data training comparison is needed.

The low-data entry is the first run because it costs almost nothing and is the cleanest external validation of the frozen model.

### Official metric contract

Use PDEBench's own `metric_func` at runtime, imported from the pinned official repository rather than copied into this repository.

Report the official metrics:
- RMSE
- normalized RMSE
- conserved-variable error
- maximum error
- boundary RMSE
- Fourier low / mid / high error

No local replacement metric is used for the headline public benchmark table.

## Priority 2 — Representative PDE Benchmarks / CNO

The official CNO repository includes Representative PDE Benchmarks covering, among others:
- Transport
- Allen-Cahn
- Wave
- Navier-Stokes
- Compressible Euler
- Darcy flow

The current IPM-v1 should first target compatible 1-D/local finite-order tasks. Multidimensional tasks require a separately validated IPM extension.

## Priority 3 — PDEArena

PDEArena provides a standardized architecture zoo and tasks such as 2-D Navier-Stokes and shallow water.

Do not force scalar 1-D IPM-v1 into these tasks.

PDEArena becomes primary only after:
- 2-D jet geometry;
- vector/multifield characteristic;
- multidimensional Cartan total derivatives;
- 2-D compiled runtime
are separately qualified and frozen.

## Priority 4 — The Well

The Well provides 16 diverse physics datasets (~15 TB total) and benchmark training infrastructure, with pretrained benchmark checkpoints available for several baselines.

Use selected compatible datasets only after multidimensional/multifield IPM is frozen.

## Cost policy

Whenever an official benchmark provides:
- pretrained checkpoints,
- published test metrics,
- official evaluation scripts,

prefer those assets over retraining the baseline.

Train only IPM unless a missing baseline result makes a direct reproduction necessary.

## Paper evidence hierarchy

Primary:
1. official public benchmark metric tables;
2. official pretrained/published baseline values;
3. frozen IPM result generated by the same official evaluator.

Secondary:
- our controlled matched-update B-series experiments;
- latency/VRAM/profiling experiments;
- classical-solver studies.

This separation prevents our own training harness from being the sole evidence for comparative performance.
